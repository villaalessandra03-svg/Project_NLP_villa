# NLP for social media exam project

This project has been created for the exam of the course "NLP for social media". The main scope of this code is to conduct sentiment analysis on book reviews taken from Amazon kindle relying on the Kaggle dataset available at this link: (https://www.kaggle.com/datasets/meetnagadia/amazon-kindle-book-review-for-sentiment-analysis).
